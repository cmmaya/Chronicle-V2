# BU136 — Import A Text Transcript As A Session

Status:
Completed

Goal:
`SessionManager.import_transcript_file(path)` creates a stopped session with
`origin = 'text'`, stores the transcript paragraphs, marks the session
transcribed and indexes it, so the existing Summarize job can run on it
unchanged.

Context:
- `SessionManager.import_audio_file` (BU104, `session_manager.py` ~line 366)
  is the model: create the session, write content, roll back the DB row and
  folder on failure, return a `Session`.
- `_summarize(session_id)` joins every `transcripts.text` row, so an inserted
  session summarizes with no changes. `SummaryGenerator` passes the session's
  start date as "Recording date" for due-date resolution.
- `transcribe_session` runs the audio pipeline. An inserted session has no
  audio, so it must not be re-transcribed (that would leave the status
  inconsistent).
- BU134: `create_session(origin=...)`, `SESSION_ORIGIN_TEXT`,
  `TRANSCRIPT_SOURCE_INSERTED`, `is_inserted_transcript`.
- BU135: `read_transcript_paragraphs`, `TranscriptImportError`.
- `index_session_content(db, session_id)` builds the RAG index; its
  transcript windowing splits by source / time / size, so identical
  timestamps are fine.

Decisions:
- Session name: the file stem (fallback `'Inserted transcript'`).
- Start time: the file's modified time. `end_time = start_time`.
- One `transcripts` row per paragraph, `source = 'inserted'`,
  `timestamp = start + i seconds` so `ORDER BY timestamp, id` keeps file
  order; `end_timestamp` and `audio_file` stay NULL.
- `transcription_status = 'transcribed'`, `status = 'stopped'`,
  `needs_finalize = 0` (startup finalize must never try to transcribe it).
- Summary is **not** generated inside the import. The UI (BU137) chains the
  existing `summarize_session` job, so a summary failure leaves a usable
  session with a "Summarize" retry, exactly like audio uploads.

Tasks:
- `import_transcript_file(file_path) -> Session`:
  - parse first; nothing is created if parsing fails
  - create the session and insert all rows in one go; on any error delete
    the session row, its transcripts and its folder, then re-raise
  - index the session; an indexing failure is logged and reported through
    `_update_status`, not raised (the session is still valid)
- `transcribe_session` and `finalize_session` skip the audio pipeline for an
  inserted session (return the current state; no error).
- `resume_stopped_session` / `load_session(with_capture=True)` refuse an
  inserted session with `ValueError("Inserted transcripts can't be
  recorded into")`.
