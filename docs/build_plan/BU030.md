# BU030 — UI Layout for Live Transcriptions

Status:
Pending

Goal:
Change the main window layout to accommodate the live transcription view.

Context:
To display the live transcriptions, we need to add a new section to the UI. This BU will change the main layout of the application from a vertical layout to a horizontal layout, with the existing controls on the left and a new area for the live transcriptions on the right.

Allowed Files:
- `src/app/window.py`

Dependencies:
Required:
- none

Blocks:
- BU031

Tasks:
1.  **Modify `src/app/window.py`:**
    - In the `MainWindow`'s `_create_central_widget` method, change the main layout from a `QVBoxLayout` to a `QHBoxLayout`.
    - Create a new `QWidget` for the left side and move all the existing controls into it. This widget will have a `QVBoxLayout`.
    - Create a new `QWidget` for the right side, which will serve as a placeholder for the live transcription view. This widget will also have a `QVBoxLayout`.
    - Add both the left and right widgets to the main `QHBoxLayout`.

Execution Sequence:
1.  **Understand:** Review the existing UI layout in `_create_central_widget`.
2.  **Implement:** Modify the layout as described above.
3.  **Validate:** Run the application and verify that the UI is now split into two sections, with the existing controls on the left and an empty space on the right.
4.  **Review Readiness:** Ensure the UI is still functional and the layout is as expected.
5.  **Document:** Update `docs/current_state.md` and `docs/devlog.md`.

Validation Requirements:

Required:
- The main window layout must be changed to a horizontal layout.
- The existing UI controls must be on the left side.
- A new empty area must be present on the right side.
- No new syntax/runtime errors should be introduced.

Tests Required:
- no

Out of Scope:
- Implementing the live transcription display.
- Adding the checkbox for live transcription.

Definition of Done:
- [ ] The main layout is a `QHBoxLayout`.
- [ ] The UI is split into a left and a right section.
- [ ] The existing controls are in the left section.
