# BU146 — Session Documents Table

Status:
Completed

Goal:
Store documents a user adds to a session as extracted text in the database,
so they survive the session ending, the window closing and an app restart,
and go away with the session.

Context:
- Session Documents (user-requested): documents added to a session become
  extra context for that session's Specific Session questions and its
  detached-window answers. They are per session, kept after the session ends,
  and stored as **text only** — the original file is not copied.
- Up to now the only document support is BU117: one `.txt` held by the open
  detached window and never persisted. BU151 moves the detached window onto
  this table; until then the two coexist untouched.
- Schema is versioned (`SCHEMA_VERSION = 4`, `database.py` ~13). New tables
  go in the `CREATE TABLE IF NOT EXISTS` block (~239-400); the version bump
  goes through `_migrate` (~466), which already backs up the file first.
- Deleting a session goes through `purge_session` (~650), which removes every
  row that belongs to the session in one transaction; `_purge_orphans`
  sweeps rows left by older deletes. Both must learn the new table.
- Documents must **not** go into `rag_documents` / `rag_chunks`: those feed
  Any Session, and documents are Specific Session only.

Tasks:
- Config: `SESSION_DOCUMENTS` block in `src/config.py`:
  - `max_per_session`: 5
  - `max_file_bytes`: 2 * 1024 * 1024
  - `allowed_extensions`: `[".txt", ".md", ".pdf", ".docx"]`
  (BU147 and BU149 add their own keys to this block.)
- Table `session_documents`:
  `id INTEGER PRIMARY KEY`, `session_id INTEGER NOT NULL` (FK to `sessions`,
  `ON DELETE CASCADE`), `name TEXT NOT NULL` (file name as shown),
  `file_type TEXT NOT NULL` (`txt|md|pdf|docx`), `file_bytes INTEGER`,
  `text TEXT NOT NULL`, `char_count INTEGER NOT NULL`,
  `added_at INTEGER NOT NULL` (epoch seconds). Index on `(session_id, added_at)`.
- `SCHEMA_VERSION = 5`; `_migrate` step `from_version < 5` creates the table
  on an existing database (the `IF NOT EXISTS` block covers new ones).
- Database methods:
  - `add_session_document(session_id, name, file_type, file_bytes, text) -> int`
    — refuses (raises `DatabaseError` with a user-readable message) when the
    session already has `max_per_session` documents or a document with the
    same name (case-insensitive). The count check and the insert happen in one
    transaction.
  - `get_session_documents(session_id) -> list[dict]` — oldest first, all
    columns.
  - `list_session_documents(session_id) -> list[dict]` — same, without `text`
    (for the pop-up list and the indicator, which must not pull megabytes of
    text to draw a row).
  - `count_session_documents(session_id) -> int`.
  - `delete_session_document(document_id) -> None`.
- `purge_session` deletes the session's documents in its transaction;
  `_purge_orphans` reports and removes documents whose session is gone.
- Nothing calls these yet outside tests.
