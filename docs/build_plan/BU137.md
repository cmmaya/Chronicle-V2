# BU137 — "Upload Transcript" Button In All Sessions

Status:
Completed

Goal:
Next to **Upload Audio** in the All Sessions window, an **Upload Transcript**
button picks a text file, imports it as a session, then summarizes it, with
the card showing progress the same way audio uploads do.

Context:
- `window.py` ~line 7202 builds the bottom bar (`upload_btn`,
  `AllSessionsUpload`). `_upload_audio_from_all_sessions` (~line 7522) is the
  flow to mirror: `QFileDialog` → `session_manager.submit_job(import)` →
  `_post_to_ui` → `dialog._focus_session(id)` → set a chip busy → chain the
  next job → `_refresh_all_sessions_window`.
- `_build_session_actions_menu` (~line 7407) offers Transcribe / Summarize /
  Resume based on status. An inserted session is already transcribed, so
  Transcribe never shows; Resume must be hidden for it.
- `_session_card_meta` builds the card's meta line (time / duration). An
  inserted session has zero duration.
- BU135: `SUPPORTED_EXTENSIONS` for the dialog filter. BU136:
  `import_transcript_file`, `summarize_session`.

Tasks:
- Bottom bar: `Upload Transcript` button (`AllSessionsUploadTranscript`,
  same height/cursor/QSS as Upload Audio), placed between Upload Audio and
  Close. Tooltip: "Add a .txt transcript as a new session and summarize it".
- `_upload_transcript_from_all_sessions(dialog)`:
  - remembers its own last folder (`_upload_transcript_dir`)
  - import job → on error: status line + warning box with the parser message
  - on success: focus the new card, set `summary_chip` busy "Summarizing",
    chain `summarize_session` as a background job, refresh on completion; a
    summary failure shows a warning and leaves the card at "Needs summary"
- Card menu: hide **Resume** when `session['origin'] == 'text'`.
- Card meta: for `origin == 'text'` show the date plus "Inserted transcript"
  instead of a duration.
