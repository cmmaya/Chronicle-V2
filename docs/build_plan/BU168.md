# BU168 — Speaker-Labelled Transcript View

Status:
Completed

Goal:
When a session has diarization enabled, its transcript in the main window
and the detached window reads by speaker instead of Mic / System.

Context:
- Bubbles today: Mic on the right in blue, System on the left in cream
  (`_add_transcription_to_view`,
  `_load_session_transcripts_for_current_session`).
- The filter menus offer All / Mic / System.

Allowed Files:
- src/app/window.py (transcript and detached views, filter menus)
- src/app/pixel_widgets.py (speaker tag on bubbles)
- src/app/theme.py (speaker colour tokens)
- tests/test_bu168.py (new)
- docs/build_plan/BU168.md
- docs/build_plan/index.md
- docs/current_state.md
- docs/devlog.md

Dependencies:
Required:

- BU169

Tasks:
- Rows with a `speaker` key show "Speaker N" instead of Mic / System.
- Layout: the speaker with the most talk time on the right (blue bubble),
  everyone else on the left (cream); each speaker's name tag in its own
  colour, so speakers on the left stay distinguishable.
- Speaker colours: 6 tokens per appearance (cycled after 6). Classic and
  Synthwave use their palettes' accents; Boring Corporate uses muted greys
  plus one accent to keep its monochrome look. Contrast checked on both
  bubble fills.
- Consecutive turns of the same speaker merge into one bubble, as today.
- The filter menus list All plus each speaker while diarized (Mic / System
  otherwise); the choice resets when diarization is switched.
- Find, copy and export use the speaker labels.
