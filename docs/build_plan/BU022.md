# BU022 — Integrate Global Hotkey for Interactive Snipping

Status:
Pending

Goal:
Connect the global hotkey `Ctrl+Shift+R` to the existing interactive region capture functionality.

Context:
BU021 established a global hotkey listener. This BU will replace the placeholder logging action with a call to the `capture_interactive_region` method, allowing users to trigger the snipping tool from anywhere. It also removes the now-redundant `QShortcut` implementation.

Allowed Files:
- `src/app/window.py`
- `src/screenshots/capture.py`
- `src/app/session_manager.py`

Dependencies:
Required:
- BU021

Blocks:
- None

Tasks:
- Modify the global hotkey callback in `MainWindow` to call a new method on the `SessionManager`.
- Create a new method in `SessionManager` named `capture_interactive_region` that calls the corresponding method on the active session's `screenshot_capture` component.
- In `ScreenshotCapture`, remove the `register_shortcuts` method and its call to `QShortcut`.
- Ensure the interactive capture is associated with the currently active session.

Execution Sequence:
1. Understand
2. Implement
3. Validate
4. Review Readiness
5. Document

Validation Requirements:

Required:
- Pressing `Ctrl+Shift+R` must activate the `SnippingOverlay`.
- Selecting a region must save a screenshot to the active session's directory.
- The feature must work when the main application window is minimized.
- The old `QShortcut` for `Ctrl+Shift+R` must be removed.

Tests Required:
- no

Out of Scope:
- Changing the hotkey combination.
- Modifying the appearance or behavior of the `SnippingOverlay`.

Definition of Done:
[ ] The `Ctrl+Shift+R` hotkey triggers the `SnippingOverlay` globally.
[ ] A successful snip saves a screenshot file and its metadata to the database for the active session.
[ ] The old `QShortcut` code is removed from `src/screenshots/capture.py`.
