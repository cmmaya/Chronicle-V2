# BU050 — Assistant Conversation Writeback

Status:
Pending

Goal:
Save each assistant question and answer after a successful response.

Context:
Conversation context is useful only if the assistant writes new turns back to SQLite after answering.

Allowed Files:
- src/assistant/service.py
- docs/current_state.md
- docs/devlog.md

Dependencies:
Required:
- BU048
- BU049

Blocks:
- BU051

Tasks:
- After answer generation succeeds, append the user question to the active session conversation.
- Append the assistant answer to the same conversation.
- Use existing session scope resolution; do not invent global memory.
- Avoid saving failed or empty assistant responses.
