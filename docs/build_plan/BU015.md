# BU015 — Trigger Transcription from UI

Status:
Pending

Goal:
Add a button to the UI to start the transcription process for a selected session.

Context:
To allow for post-session processing, users need a way to manually trigger transcription for sessions that have not yet been transcribed. This BU adds the UI element and wiring to make that possible.

Allowed Files:
- `ui/main_window.py`
- `transcription_processor.py`
- `session_manager.py`

Dependencies:
Required:
- BU014

Blocks:
- BU017

Tasks:
- Add a "Transcribe" button to the UI for each session that is not yet transcribed.
- Implement the logic in `ui/main_window.py` to handle the button click.
- The button click should trigger the transcription process for the selected session, likely via `session_manager.py`.
- The UI should provide feedback that transcription is in progress (e.g., disable the button, show a status message).
