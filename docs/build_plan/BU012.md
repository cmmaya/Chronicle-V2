# BU012 - Fix Transcription Pipeline to Use Real Speech-to-Text Model

**Status:** Pending

**Goal:**
Diagnose and fix the issue preventing the `TranscriptionProcessor` from loading and using a real speech-to-text model. Ensure that audio chunks are transcribed using a genuine speech-to-text engine, replacing the current mock transcription placeholders.

**Context:**
The transcription pipeline is currently falling back to a `MockTranscriber` because neither `parakeet-ctc` nor `coqui-stt` libraries can be imported. This results in placeholder "mock" transcripts. This BU will ensure the necessary dependencies are installed and the `ParakeetV3` class can successfully load a real transcription model. The original goal of BU012 (merging transcripts) is blocked by this issue and will be moved to BU013.

**Allowed Files:**
- `src/transcription/parakeet.py`
- `src/transcription/processor.py`
- `requirements.txt`

**Dependencies:**
- None

**Blocks:**
- BU013 (the new transcript merger BU)

**Tasks:**

1.  **Modify `parakeet.py`:** In `src/transcription/parakeet.py`, modify the `load` method in the `ParakeetV3` class. Remove the final fallback to the mock transcriber. If both `parakeet` and `coqui-stt` fail to load, it should raise a `ModelLoadError`.
2.  **Update `processor.py`:** In `src/transcription/processor.py`, ensure that any code calling `parakeet.load()` or `parakeet.transcribe()` is wrapped in a try/except block to catch the `ModelLoadError` and log a clear, informative error message.
3.  **Update Dependencies:** Add `coqui-stt` to `requirements.txt`. The version should be compatible with the project's Python version. A good starting point would be a recent, stable version.
4.  **Verify:** After the changes, confirm that the system attempts to load the Coqui STT model. If the model files are missing, it should fail with a clear error. If the library is correctly installed and model files are present, it should produce a real transcription.

**Out of Scope:**
- Implementing the transcript merger (this will be BU013).
- Downloading or providing the STT model files. This BU is focused on the code changes to support the model.

**Definition of Done:**
- [ ] The `ParakeetV3.load()` method in `src/transcription/parakeet.py` is modified to raise a `ModelLoadError` if no real model can be loaded.
- [ ] The mock transcriber fallback in `parakeet.py` is removed.
- [ ] The `TranscriptionProcessor` in `src/transcription/processor.py` gracefully handles the `ModelLoadError`.
- [ ] `coqui-stt` is added to `requirements.txt`.
- [ ] The application produces a clear error message if the STT model cannot be loaded, instead of silently falling back to a mock implementation.

**Reviewer Focus:**
- The error handling for model loading is robust and provides clear error messages.
- The dependency update is correct.
- The silent fallback to the mock transcriber is completely eliminated.
