# BU143 — Search Terms: Stop Words, Stems, Follow-Ups

Status:
Completed

Goal:
Questions no longer need the transcript's exact word: question words stop driving the ranking, inflections match, and short follow-ups search with the previous question.

Context:
- `sanitize_fts_query` OR-ed every word, so "what/did/the/at" matched nearly every chunk and decided the BM25 order; the FTS table has no stemming, so "advices" missed "advice".
- A follow-up like "is it about a report?" was searched on its own.

Tasks:
- `database.fts_terms`: lowercase, drop `QUERY_STOP_WORDS` (all kept if nothing else is left), light suffix strip (`ing`/`es`/`ed`/`s`), dedupe. `sanitize_fts_query` emits `"term"*` prefix queries joined by OR - no reindex needed. Also used by All Sessions search and the router.
- The in-memory search (`_extract_keywords`) uses the same terms as prefixes.
- `_search_query`: a question with fewer than 3 terms is searched together with the previous user question; the persisted question is unchanged.
- Existing sanitizer / keyword tests updated to the new output.
