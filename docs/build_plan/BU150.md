# BU150 — Document Badge On Chat Answers And A Documents Indicator

Status:
Completed

Goal:
A chat answer that used a session document shows a badge naming the
document(s); and while the chat is scoped to a session that has documents, a
small indicator says so, so the user knows answers draw on them.

Context:
- User decision: answers built from a document are marked with a **UI
  badge**, not inline text.
- BU149 returns `AnswerResponse.document_refs` (`id`, `name`) and stores a
  normalised `Documents used: D<id>, ...` line in the persisted assistant
  message.
- Chat answers render through `_add_message_to_conversation` (`window.py`
  ~3504), which also mirrors into the detached window's chat
  (`_add_message_to_detached_conversation`). The main handler that receives
  `response` (~6640) already adds screenshot buttons after the bubble
  (`_add_screenshot_refs_to_conversation`); the badge goes in the same place.
  The detached chat's own handler (`_run_detached_assistant_query`, ~9078)
  does the same.
- Reopening a past conversation re-renders stored messages (~1273, where
  BU108 re-parses the screenshot line). The badge is rebuilt there from the
  stored line; a document deleted since then shows as "(removed document)".
- `_update_scope_label` (~7063) is called on every scope / session change —
  the hook for the indicator.
- Entry point for managing documents stays the All Sessions menu (BU148). The
  indicator opens the same pop-up as a shortcut; it is not a second
  management UI.

Tasks:
- `PixelDocumentBadge` widget in `pixel_widgets.py`: a small chip under an
  assistant bubble, document icon + "From: syllabus.pdf" (several names
  comma-separated, elided past ~40 chars with the full list in the tooltip).
  Same pixel vocabulary as the BU117 reference chip.
- Live answers: when `response.document_refs` is non-empty, add the badge
  right after the answer bubble (before any screenshot buttons), in the main
  chat and the detached chat.
- Reopened conversations: when an assistant message has the stored
  `Documents used:` line, strip it from the bubble text and add the badge;
  ids no longer in the session render as "(removed document)".
- Indicator: next to the scope label, a chip "📄 N documents" visible only
  when scope is Specific Session **and** the scoped session has ≥1 document.
  Updated from `_update_scope_label` and on the BU148 `documents_changed`
  signal. Clicking opens `SessionDocumentsDialog` for that session.
- Nothing is shown when there are no documents: no empty badge, no "0
  documents" chip.
