# BU101 — Transcript Download Button

Status:
Completed

Goal:
Add a download button to the Transcripts Window panel, next to the existing
filter and detach buttons, that saves the currently displayed transcript
stream to a `.txt` file in the user's Windows Downloads folder and shows a
status notification when the save completes.

Context:
The user asked for a download control in the transcripts panel, matching the
existing pixel-themed toolbar buttons in look and placement, plus a
notification confirming the save.

Allowed Files:
- src/app/window.py
- assets/pixel/icon_download.svg
- docs/build_plan/index.md
- docs/current_state.md
- docs/devlog.md

Dependencies:
Required:
- none

Blocks:
- none

Tasks:
- Add a new pixel-art `icon_download.svg` asset (same style/palette as
  `icon_export.svg`) depicting a download glyph.
- In `_build_transcripts_panel`, add a `download_transcript_button`
  (`PixelToolButton`, same size/icon pattern as `transcript_filter_button` and
  `detach_transcription_button`) placed in the same top button row.
- Wire it to a new `_on_download_transcripts` handler that:
  - Builds the export text from `self._transcription_history` (already
    formatted `[HH:MM:SS] Source: text` lines).
  - Shows a message via `_on_status_update` and returns early if there is
    nothing to export.
  - Resolves the session name (selected session via `db.get_session`, else
    the active session, else "session") to build a filename, e.g.
    `chronicle_transcript_<session_name>_<YYYYMMDD_HHMMSS>.txt`.
  - Writes the file to `QStandardPaths.writableLocation(QStandardPaths.DownloadLocation)`.
  - Calls `_on_status_update` with a success message including the filename
    on success, or an error message (`is_error=True`) on failure.
