# BU029 — Display Live Transcriptions in UI

Status:
Pending

Goal:
Display live transcriptions in the UI as they are generated during a recording session.

Context:
BU028 implemented the live transcription functionality that saves transcripts to the database. This BU will display those transcriptions in the UI in real-time.

Allowed Files:
- `src/app/window.py`

Dependencies:
Required:
- BU028 (live transcription saves to database)

Blocks:
- None

Tasks:
1.  **Modify `src/app/window.py`:**
    - Add a live transcription display area in the main window (e.g., a QTextEdit or QListWidget)
    - Pass a callback function to SessionManager's `live_transcription_ui_callback` parameter
    - The callback should receive transcription results and display them in the UI
    - Format: Show timestamp, source (mic/system), and text for each transcription
