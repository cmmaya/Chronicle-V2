# BU127 — Windows Installer With A Choosable Install Folder

Status:
Completed

Goal:
A single `ChronicleSetup-<version>.exe` that installs the BU126 app folder
into any path the user picks, creates shortcuts, installs prerequisites and
provides a clean uninstaller. The installer then launches Chronicle straight
into the BU124 setup wizard.

Context:
- Inno Setup 6 is a free, scriptable installer with a standard "Select
  Destination Location" page. It is the simplest fit for a PyInstaller onedir
  build.
- Installing per user by default (`%LOCALAPPDATA%\Programs\Chronicle`) needs
  no administrator rights. The user can still pick any folder, including
  `C:\Program Files` (which triggers an admin prompt) or another drive.
  BU121 makes a read-only install folder safe.
- User data and models live in the data folder chosen in the wizard, not in
  the install folder. An upgrade or a reinstall therefore never touches them.
- The VC++ runtime dependency is confirmed by BU126's clean-VM test.
- Recording and screen capture from an unsigned installer will trigger
  SmartScreen ("Windows protected your PC"). Code signing is noted here but
  kept out of scope.

Tasks:
- `chronicle.iss`:
  - `AppId` as a fixed GUID, so upgrades replace the previous version in place.
  - `PrivilegesRequiredOverridesAllowed=dialog`, so the user chooses "just me"
    (default, no admin) or "all users".
  - `DefaultDirName={autopf}\Chronicle` and a visible directory page, so any
    path can be chosen.
  - Start-menu shortcut and an optional desktop shortcut.
  - Bundle `vc_redist.x64.exe` and run it silently only if the runtime is
    missing (registry check).
  - Final page: "Launch Chronicle" (checked), which opens the setup wizard.
  - Refuse to install or uninstall while Chronicle is running
    (`AppMutex`, matched to the BU125 single-instance name).
- Uninstaller: removes the app folder and shortcuts. It then asks whether to
  also delete the user data and models, showing the data-folder path read
  from the BU121 pointer file. The default is to keep them.
- `build.ps1` gains a step that runs `ISCC` after PyInstaller and writes
  `dist\ChronicleSetup-<APP_VERSION>.exe`.
- `docs/setup.md`: a "Building the installer" section.

Validation Requirements:

Required:
- executable behavior verified
- no syntax/runtime errors
- Definition of Done satisfied
- manual validation on a clean Windows 11 VM:
  - A per-user install to the default path, with no admin prompt, launches
    into the wizard.
  - An install to a custom path on another drive works, and the app runs.
  - An all-users install to `C:\Program Files\Chronicle` shows the admin
    prompt and the app runs as a normal user.
  - Installing version N+1 over N keeps the sessions, key and models.
  - Uninstalling and keeping data leaves the data folder intact, and a
    reinstall picks it up with no wizard. Uninstalling and deleting data
    leaves nothing behind.
  - Running the installer while Chronicle is open is blocked with a message.

Tests Required:
- no — installer behaviour is verified by the VM checklist above
