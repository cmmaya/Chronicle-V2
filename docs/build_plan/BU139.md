# BU139 — Inserted Transcript Mode In The Detached Window

Status:
Completed

Goal:
When an inserted transcript is detached, the window shows the text only:
an "Inserted Transcript" caption under **TRANSCRIPTS**, plain cream bubbles,
and every transcript-only control (filter, DETECT / ANSWER chips, chunk
selection, right-click ask) disabled and shown unselected.

Context:
- `_on_detach_transcription` (~line 4035) builds `DetachedTranscriptsDialog`
  with two columns:
  - `_build_detached_answers_column` (~line 4133): DETECT chips
    (`_live_qa_mode_chips`: Manual / Suggest / Auto), ANSWER chips
    (`_live_qa_answer_mode_chips`), the ⚙ detection settings button, the
    empty hint "Click or drag across transcript chunks…".
  - `_build_detached_transcript_column` (~line 4341): header
    `PixelSectionTitle("TRANSCRIPTS")`, filter button, pin button.
- `_add_transcription_to_detached` (~line 5544) prefixes "Mic:" / "System:",
  groups by time and calls `_install_bubble_selection(row)` (BU113), which
  makes chunks clickable / draggable and drives the right-click ask menu.
- `_sync_live_qa_mode_chips` / `_sync_live_qa_answer_mode_chips` paint the
  checked chip from the saved mode.
- BU138: `self._displaying_inserted_transcript` and the plain
  `TranscriptRecord`s (`source='inserted'`).

Decisions:
- Caption "Inserted Transcript" under the TRANSCRIPTS title (same style as
  BU138).
- Disabled and visually unselected (no chip checked) while inserted: filter,
  DETECT chips, ANSWER chips, ⚙ settings. The saved modes are **not**
  changed; they repaint as before when a recorded session is shown.
- Bubbles get no selection filter, so clicks, drags and right-click ask do
  nothing. Pin and the answers collapse toggle keep working.
- Answers empty hint reads "Answers aren't available for inserted
  transcripts". Existing answer cards stay as they are.
- Dropping a reference `.txt` (BU117) is left enabled; it does nothing
  without the ask flow, but it is harmless.
