# BU028 — Real-time Transcription in SessionManager

Status:
Pending

Goal:
Implement the logic in `SessionManager` to handle the live transcription of an audio chunk.

Context:
This BU will connect the `live_transcription_callback` from the previous BU to the transcription backend. It will implement the logic in `SessionManager` to receive an audio chunk, transcribe it, and prepare the result for the UI.

Allowed Files:
- `src/app/session_manager.py`
- `src/transcription/` (specific file to be determined, likely a new file for live transcription)

Dependencies:
Required:
- BU027

Blocks:
- BU029

Tasks:
1.  **Create a new file for live transcription:**
    - Create a new file, e.g., `src/transcription/live.py`.
    - In this file, create a function that takes an audio file path and returns the transcription. This function will use the `faster-whisper` library.
2.  **Modify `src/app/session_manager.py`:**
    - In the `SessionManager` class, create a new method, e.g., `handle_live_transcription`, that takes an `AudioChunk` object.
    - This method will call the transcription function from `src/transcription/live.py`.
    - The result of the transcription should be passed to a new callback, e.g., `live_transcription_ui_callback`, which will be used in a later BU to update the UI.
    - In the `start_session` method, pass the `handle_live_transcription` method as the `live_transcription_callback` to the `DualSourceChunkedRecorder`.

Execution Sequence:
1.  **Understand:** Review the `faster-whisper` documentation to understand how to use it for real-time transcription. Review the `SessionManager` class.
2.  **Implement:** Create the new transcription function and the `handle_live_transcription` method in `SessionManager`.
3.  **Validate:** Add a temporary print statement in the `live_transcription_ui_callback` to verify that the transcription result is received. Run the application, record a session, and check the console output for the transcription.
4.  **Review Readiness:** Ensure the transcription is working correctly and doesn't block the UI.
5.  **Document:** Update `docs/current_state.md` and `docs/devlog.md`.
