# BU128 — Settings Pop-Up Window

Status:
Completed

Goal:
Replace the hidden Qt menu bar that the sidebar "Settings" button toggles at
the top of the window with a single pixel-art pop-up window. The pop-up groups
every setting into sections, applies changes immediately and matches the
navy/cream look of the rest of the app.

Context:
- Before this BU, `MainWindow._create_menu_bar` built a stock `QMenuBar`
  (File / Session / Settings / Help). `_create_central_widget` hid it, and the
  sidebar Settings button toggled it with
  `menuBar().show() if menuBar().isHidden() else menuBar().hide()`. The bar
  showed up as an unstyled native strip above the custom pixel title bar. It
  pushed the workspace down and did not look like part of the app.
- Three of the menu items opened their own plain `QDialog`s:
  `_show_vad_settings`, `_show_model_settings` and `_show_api_key_settings`
  (BU122). The rest were checkable `QAction`s: live transcription, auto
  summary and show log messages (BU119 persisted), plus `Reindex All (RAG)`
  (BU091).
- The checkable `QAction`s are the state model other code reads
  (`live_transcription_action.isChecked()` when starting a session,
  `_save_preferences`, `_apply_preferences`, and `_reindex_action.setEnabled`
  while a reindex runs). Keeping them as the source of truth, without a menu
  bar, means none of those readers change.
- File › Exit, Session › Start/Stop and Help › About have no other entry in the
  menu bar. Exit is the title bar's close button. Start/Stop are the
  recording controls. About moves into the pop-up.
- `PixelWindowChrome` (`pixel_widgets.py`) already gives every `QDialog` the
  frameless pixel title bar and edge resize, so the pop-up gets its chrome for
  free.

Tasks:
- New `src/app/settings_dialog.py`:
  - `PixelToggle`: a painted, chunky on/off switch (blue track and cream knob
    when off, gold track when on). Clickable and keyboard-toggleable
    (Space/Enter), with a `toggled(bool)` signal.
  - `SettingsDialog(QDialog)`: a left navigation rail and a `QStackedWidget`
    of pages:
    - **General**: live transcription, auto summary, show log messages
      (toggles).
    - **Audio**: VAD speech threshold (5–100 %) and aggressiveness (0–3)
      as pixel-styled sliders with live value readouts.
    - **Model**: the summarization/assistant model (combo box over
      `ALLOWED_MODELS`).
    - **API Key**: the BU122 flow (masked current key, Test / Save /
      Remove), unchanged in behaviour.
    - **Maintenance**: Reindex All (RAG). Its button follows
      `_reindex_action`'s enabled state.
    - **About**: app name and description.
  - Each setting is a row card: a title and a muted description on the left,
    the control on the right.
  - Changes apply immediately, so there is no OK/Cancel. The footer says
    "Changes save automatically" and has a Done button. Esc also closes.
  - Pop-in animation: opacity 0→1 and a short upward slide (~160 ms,
    OutCubic). A navy scrim dims the main window while the dialog is open.
- `window.py`:
  - `_create_menu_bar` becomes `_create_settings_actions`. It builds the same
    checkable `QAction`s and `_reindex_action` but no `QMenuBar`, and the
    window never calls `setMenuBar`.
  - The Settings sidebar button and a `Ctrl+,` shortcut open
    `SettingsDialog`. Only one dialog can be open at a time.
  - Add `_apply_vad_settings(threshold, aggressiveness)` and
    `_apply_selected_model(model_id)`, which hold the side effects that used
    to follow the old dialogs' OK. The pop-up calls them.
  - Remove `_show_vad_settings`, `_show_model_settings` and `_show_about`.
    Move the body of `_show_api_key_settings` into the pop-up's API Key page.

Validation Requirements:

Required:
- executable behavior verified
- no syntax/runtime errors
- Definition of Done satisfied
- manual validation:
  - Clicking Settings opens a centered pop-up with the pixel title bar. The
    main window dims, and no native menu strip appears anywhere.
  - Each toggle flips its setting. Reopening the pop-up, and restarting the
    app, both show the stored value.
  - Moving the VAD sliders updates the readout. The next recording uses the
    new values.
  - Changing the model updates the status line and survives a restart.
  - API Key: Test / Save / Remove behave as in BU122.
  - Reindex asks for confirmation, and its button stays disabled while the
    reindex runs.
  - Esc, Done and the title bar ✕ all close the pop-up and remove the scrim.

Tests Required:
- yes — `tests/test_bu128.py`:
  - the main window has no visible menu bar and no Settings `QMenu`
  - each toggle writes through to its `QAction`, and the dialog reflects the
    `QAction` state on open
  - the VAD and model controls call the window's apply methods
  - the Reindex button mirrors `_reindex_action.isEnabled()`
  - `PixelToggle` flips on click and on Space

Out of Scope:
- Persisting VAD settings across restarts (they remain session-only, as before)
- New settings that did not exist in the menu
- Restyling other dialogs (search, reindex confirmation)
