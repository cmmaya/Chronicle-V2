# BU085 — Implement RAG Content Indexing

Status:
Pending

Goal:
Populate the RAG tables (`rag_documents`, `rag_chunks`) and FTS index (`rag_fts`) with content from session transcripts and summaries.

Context:
The RAG search functionality is currently not working because the underlying tables are empty. This BU connects the session processing pipeline to the RAG indexing methods to make session content searchable.

Allowed Files:
- `src/rag/indexer.py` (new file)
- `src/app/session_manager.py`
- `tests/test_rag_indexer.py` (new file)
- `docs/current_state.md`
- `docs/devlog.md`

Dependencies:
Required:
- BU084

Blocks:
- none

Tasks:
- Create a new module `src/rag/indexer.py`.
- In `indexer.py`, implement a function `index_session_content(db, session_id)` that:
    - Fetches all transcripts for the given `session_id`.
    - Upserts a `rag_document` for the full transcript.
    - Chunks the transcript text and calls `replace_rag_chunks`.
    - Fetches all summaries for the `session_id`.
    - Upserts a `rag_document` for each summary.
    - Chunks the summary text and calls `replace_rag_chunks`.
- In `session_manager.py`, after a transcription process is completed, call `indexer.index_session_content`.
- In `session_manager.py`, after a summary is generated, call `indexer.index_session_content`.
- After indexing is complete, call `db.rebuild_rag_fts()` to make the content searchable.
- Add tests in `tests/test_rag_indexer.py` to verify that the indexer correctly populates the database tables.
- Update `docs/current_state.md` and `docs/devlog.md`.

Execution Sequence:
1. Understand

Validation Requirements:

Required:
- After a session's transcription is finished, its content is searchable via the assistant.
- After a summary is generated, its content is searchable.
- The `rag_documents`, `rag_chunks`, and `rag_fts` tables are correctly populated.

Tests Required:
- yes

If yes:
- Test that `index_session_content` creates one document for a transcript and one for a summary.
- Test that the content is correctly chunked and stored in `rag_chunks`.
- Test that `rebuild_rag_fts` is called.

Out of Scope:
- Do not index screenshots.
- Do not perform live indexing while a session is active. Indexing will occur after a process (transcription, summarization) completes.
- Do not change the assistant service or UI files.
