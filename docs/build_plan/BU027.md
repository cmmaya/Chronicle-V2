# BU027 — Live Transcription Callback

Status:
Pending

Goal:
Add a callback mechanism to the `ChunkedAudioRecorder` to trigger live transcription for each new audio chunk.

Context:
To implement live transcriptions, we need a way to process each audio chunk as it's recorded. This BU will add a callback to the `ChunkedAudioRecorder` that will be called whenever a new chunk is saved. This callback will be used in a later BU to trigger the transcription process.

Allowed Files:
- `src/audio_capture/core.py`

Dependencies:
Required:
- BU026

Blocks:
- BU028

Tasks:
1.  **Modify `src/audio_capture/core.py`:**
    - In the `ChunkedAudioRecorder` class, add a new callback parameter to the `__init__` method, e.g., `live_transcription_callback`.
    - In the `_save_chunk` and `_save_chunk_from_array` methods, after a chunk is saved, call the `live_transcription_callback` with the `AudioChunk` object.
    - In the `DualSourceChunkedRecorder`, propagate the `live_transcription_callback` to the individual `ChunkedAudioRecorder` instances.

Execution Sequence:
1.  **Understand:** Review the `ChunkedAudioRecorder` and `DualSourceChunkedRecorder` classes.
2.  **Implement:** Add the new callback mechanism.
3.  **Validate:** Add a temporary print statement inside the new callback to verify that it's being called for each new chunk. Run the application and record a short session. Check the console output for the print statements.
4.  **Review Readiness:** Ensure the callback is working as expected and doesn't block the recording process.
5.  **Document:** Update `docs/current_state.md` and `docs/devlog.md`.
