# BU026 — VAD Integration

Status:
Pending

Goal:
Integrate WebRTC Voice Activity Detection (VAD) to avoid recording and processing silent audio chunks.

Context:
Currently, the application records audio continuously, including periods of silence. This wastes storage and processing power. This BU will integrate a VAD to detect and discard silent audio chunks.

Allowed Files:
- `src/audio_capture/core.py`
- `requirements.txt`

Dependencies:
Required:
- BU025

Blocks:
- BU027

Tasks:
1.  **Add `webrtcvad-wheels` to `requirements.txt`:**
    - This package provides pre-compiled wheels for `webrtcvad`.
2.  **Modify `src/audio_capture/core.py`:**
    - In the `ChunkedAudioRecorder`'s `_recording_loop`, initialize a `webrtcvad.Vad` object.
    - In the audio callback, before saving a chunk, use the VAD to check if the audio buffer contains speech.
    - Only save the chunk if it contains speech.
    - The VAD works with 16-bit mono audio. Ensure the audio data is in the correct format before passing it to the VAD.

Execution Sequence:
1.  **Understand:** Research the `webrtcvad` library and how to use it. Understand how to convert the audio data from `sounddevice` to the format required by the VAD.
2.  **Implement:** Modify the `_recording_loop` to incorporate the VAD.
3.  **Validate:** Run the application and record a session with periods of silence. Verify that silent chunks are not saved. Check the logs for any VAD-related errors.
4.  **Review Readiness:** Ensure that the VAD integration is working correctly and doesn't introduce any performance issues.
5.  **Document:** Update `docs/current_state.md` and `docs/devlog.md`.
