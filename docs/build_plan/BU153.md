# BU153 — Theme Engine: Style Tokens Beyond Colour

Status:
Completed

Goal:
Let a theme change shape and type, not only colours, so a "Boring
Corporate" appearance (sans-serif type, hairlines, rounded corners,
antialiasing) can restyle every window while Classic and Synthwave render
exactly as before.

Context:
- User request (2026-10-10): redesign every window as a corporate dark
  minimalist interface, selectable as the appearance "Boring Corporate",
  following a ChatGPT-style reference: thin small icons, rounded edges, white
  and grey, clean type; "as similar as possible".
- `theme.py` (BU129) only recolours: `REMAP` + `ROLES`, a `setStyleSheet` hook,
  recoloured SVGs. Courier New (~95 `QFont` sites), pixel-cut corners
  (`pixel_round_rect_path`, 45+ calls), antialiasing off and 2-3px borders are
  hardcoded across `src/app`.
- The reference is rendered in Segoe UI (ChatGPT's Windows font stack). Plain
  "Segoe UI" has a true Semibold for weight 600 under Qt 6.6; "Segoe UI
  Variable Text" only exposes Regular/Bold. So the theme uses the system font
  instead of bundling Inter (decision changed from the plan: no download, no
  spec change, closer to the reference).

Tasks:
- `BORING_CORPORATE = "boring_corporate"` in `THEMES` ("Boring Corporate").
- `STYLE` per theme: `pixel`, `font` ("Segoe UI"), `display_font` ("Segoe UI
  Variable Display"). Helpers `is_pixel()`, `is_corporate()`, `font_family()`,
  `display_font_family()`, `font(pt, bold)`, `antialias()`, `pen_width(w)`,
  `corner_radius(cut)`, `rounded_rect_path(x, y, w, h, r)` (half-pixel aligned,
  radius clamped to a pill).
- `restyle(text)`: non-pixel themes only - Courier New -> theme font, bold /
  600-900 -> 600, letter-spacing -> 0, 2-9px borders -> 1px (left edges 2px),
  3-7px radii -> 6/10px, px font sizes >= 13 down by 1. Everything after the
  `NATIVE_QSS` marker is left as written. `remap()` (hook and HTML) runs it.
- `activate()` swaps `PySide6.QtGui.QFont` for a subclass (non-pixel themes)
  that maps the Courier New family, makes bold DemiBold, caps weights at 600
  and drops letter spacing - so no `QFont("Courier New")` site needs a branch.
- `pixel_round_rect_path` returns `rounded_rect_path` in a non-pixel theme;
  every `setRenderHint(Antialiasing, False)` reads `theme.antialias()`; every
  2px `QPen` reads `theme.pen_width()`.
- `install_pixel_window_chrome` sets the app font, palette and `app_wide_qss()`
  (tooltips, menus, message boxes) for a non-pixel theme.
