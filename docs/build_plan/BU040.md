# BU040 — Assistant Session Resolver

Status:
Completed

Goal:
Infer whether a question targets current session, selected session, all sessions, or an ambiguous session.

Context:
The assistant should infer session scope when possible and ask for clarification when it cannot identify a single session safely.

Allowed Files:
- src/assistant/session_resolver.py
- docs/current_state.md
- docs/devlog.md

Dependencies:
Required:

- BU039

Tasks:
- Create AssistantSessionResolver with resolve(question, active_session_id=None, selected_session_id=None, explicit_scope=None).
- If explicit_scope is current_session, prefer active_session_id then selected_session_id.
- If explicit_scope is any_session, return all_sessions scope.
- Detect cross-session wording such as all sessions, previous sessions, compare, where did we discuss.
- Use db.find_sessions for named/dated/keyword session inference.
- Return ambiguous with candidates when more than one plausible session exists.
- Return needs_clarification when no session can be inferred.
