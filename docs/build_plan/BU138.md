# BU138 — Inserted Transcript View In The Main Transcripts Panel

Status:
Completed

Goal:
When the displayed session is an inserted transcript, the main panel shows
the text as plain cream bubbles (no "Mic:" / "System:" prefix, no time), an
"Inserted Transcript" caption under **TRANSCRIPTS WINDOW**, and the filter
button disabled in its unselected look.

Context:
- `_build_transcripts_panel` (~line 3069): filter / download / detach
  `PixelToolButton`s, then `PixelSectionTitle("TRANSCRIPTS WINDOW")`.
- `_load_transcripts_for_session` (~line 3650) turns each row into a
  `TranscriptRecord` and calls `add_transcription_to_view`, which prefixes
  "Mic:" / "System:", picks blue-right or cream-left, and groups by time.
- `_clear_transcription_view` (~line 3341) resets the panel when the session
  changes. Live chunks append via `_append_transcription`.
- `_on_download_transcripts` writes `_transcription_history` to a `.txt`.
- BU134: `db.is_inserted_transcript(session_id)`; rows have
  `source = 'inserted'`.
- The user's screenshot is the target look: cream bubble, left tail, text
  only, a blank line between paragraphs.

Decisions:
- One cream, left-aligned bubble per paragraph, no time label, no grouping.
- Caption: small muted label "Inserted Transcript" centred directly under the
  title; hidden for every other session.
- Filter button: disabled and kept in its default (unselected) colour;
  tooltip "Not available for inserted transcripts". Download and Detach keep
  working.
- Download of an inserted session exports the paragraphs as-is (blank line
  between them, no prefixes).
- While an inserted session is displayed, live chunks do not append to the
  panel.
