# BU126 — PyInstaller Build Of A Standalone App Folder

Status:
Completed

Goal:
Produce a self-contained `dist\Chronicle\` folder whose `Chronicle.exe` runs
on a Windows machine with no Python installed. No models are bundled; the
BU124 wizard fetches them.

Context:
- The runtime dependency set is defined by BU120's cleaned
  `requirements.txt`. The build must use a clean venv made from it, because
  the current `.venv312` holds Whisper-era packages (numba, llvmlite,
  ctranslate2, ...) that PyInstaller would bundle.
- Libraries known to need packaging help:
  - `onnxruntime` 1.20.1: native DLLs, plus the MSVC runtime (VC++
    2015-2022 redistributable) on the target machine;
  - `PySide6`: Qt plugins (platforms, styles, imageformats for the SVG icons
    -> `qsvg`), handled by PyInstaller's hooks. Unused Qt modules
    (WebEngine, 3D, Multimedia, ...) should be excluded to cut size;
  - `soundcard`: reads `.h` / `.py.h` cffi definition files at import, which
    must be collected as data;
  - `sounddevice` / `soundfile`: bundled PortAudio / libsndfile DLLs;
  - `av`: FFmpeg DLLs;
  - `webrtcvad`, `tokenizers`: compiled extensions;
  - `onnx_asr`: may ship data files (preprocessor ONNX graphs), so collect its
    package data;
  - `keyring`: the Windows backend is chosen by entry point, so it needs a
    hidden import.
- `--onedir`, not `--onefile`. Onefile unpacks the whole bundle to a temp
  folder on every launch, which is slow at this size and more likely to
  trigger antivirus false positives.
- `assets/` is read through `resource_dir()` (BU121).

Tasks:
- `packaging/build.ps1`: create a throwaway venv from
  `requirements.txt` + `pyinstaller`, run the spec, and print the resulting
  folder size. It is one command end to end.
- `chronicle.spec`: entry `src/main.py`; windowed; icon and version info;
  collect `assets/`; `collect_data_files` / `collect_dynamic_libs` for the
  libraries listed above; exclude `tests`, `pytest`, `tkinter` and unused Qt
  modules. It must never include `chronicle.db`, `sessions/`,
  `preferences.json`, `.env` or `*.wav` from the repo root.
- Add a single `APP_VERSION` constant (in `src/config.py` or
  `src/__init__.py`) used by the version resource and shown in the wizard and
  the About entry.
- Ignore `build/` and `dist/` in git.
