# BU034 — Assistant Conversation Storage

Status:
Completed

Goal:
Persist assistant conversations and messages for active and past session chat history.

Context:
The assistant UI needs durable conversation history so users can revisit previous agent conversations without relying on chat state.

Allowed Files:
- src/storage/database.py
- docs/current_state.md
- docs/devlog.md

Dependencies:
Required:
- none

Blocks:
- BU035
- BU047

Tasks:
- Add minimal SQLite tables for assistant conversations and assistant messages.
- Add database methods to create/list conversations by session scope and add/list messages.
- Keep records linked to session_id when available and allow null session_id for all-session conversations.
- Use plain text payloads only; do not store screenshots or audio binaries.
