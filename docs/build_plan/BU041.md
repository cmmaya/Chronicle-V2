# BU041 — Whitelisted Assistant Retrieval Tools

Status:
Completed

Goal:
Expose controlled retrieval tools that the answer service can use without giving the model raw database access.

Context:
The system should be more powerful than fixed prompts while still avoiding SQL generated by the agent. Tools wrap safe retriever/database calls.

Allowed Files:
- src/assistant/tools.py
- docs/current_state.md
- docs/devlog.md

Tasks:

- Each tool delegates to AssistantContextRetriever or Database methods.
- Return plain dict/list outputs suitable for prompt assembly.
- Validate limits and reject empty or oversized queries with clear errors.
