# BU157 — Main Window Layout

Status:
Completed

Goal:
The main window looks like the reference: flush sidebar with the brand
and a sidebar-toggle icon, flat nav rows, a centred "Where should we begin?"
over an input pill with a round send button, assistant answers as plain text,
hairline dividers between columns.

Context:
- The plan also listed "+" and mic buttons inside the input pill. They were
  left out: the app has no attach/dictate action for them, and the mute
  toggles already sit above the chat. Only the send button (which asks, like
  Ctrl+Enter) was added.

Tasks:
- Columns: spacing 0 and 1px `#262626` dividers (`_make_column_divider`).
- Sidebar: 18px semibold brand, 36px ghost panel-left toggle, 20px nav icons,
  flat history list under a "Past conversations" label, session controls
  under a hairline as 40px ghost circles (`_rail_button_size`); collapsed rail
  64px.
- Centre: 46px hairline search pill; 60px grey input pill (radius 30) with
  the agent combo and a 36px white send button (disabled while the question
  is empty, `_sync_send_button`); muted 12px log lines.
- Empty state: `_build_empty_chat_state` puts the 28px heading over the input
  pill between two expanding spacers and hides the answers area while the
  answers container has no child widget (`_chat_is_empty`, synced on
  ChildAdded / ChildRemoved / LayoutRequest, re-attached when
  `_load_conversation` swaps the container).
- Fix (2026-10-10, user-reported "the first message does not appear"): the
  sync ran synchronously on ChildAdded, which Qt sends in the middle of the
  row's reparenting; showing the hidden answers area then left the new row
  explicitly hidden. The sync is now deferred with `QTimer.singleShot(0)`.
- Answers: `_answer_variant()` = "plain", width 720 (user bubbles 460).
- Transcript viewport flat.
