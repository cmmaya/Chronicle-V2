# BU023 — Implement Overlapping Audio Chunking

Status:
Pending

Goal:
Modify the `AudioRecorder` to save audio in continuous, overlapping chunks to prevent word loss at boundaries.

Context:
The current recorder saves a single file per recording session. To improve real-time transcription and prevent data loss between segments, we need to switch to a chunk-based system. This BU introduces a 10-second buffer with a 1-second overlap, which will be the foundation for improved transcription processing.

Allowed Files:
- `src/audio/recorder.py`

Dependencies:
Required:
- none

Blocks:
- BU024

Tasks:
- Modify `AudioRecorder` to maintain a continuous internal buffer.
- Implement a mechanism to periodically save the last 10 seconds of audio from the buffer to a new `.wav` file.
- Ensure there is a 1-second overlap between consecutive saved chunks.
- The recorder should no longer save a single large file on `stop_recording`. Instead, it should manage a continuous stream of chunks.

Execution Sequence:
1. Understand: Review the current implementation of `AudioRecorder` in `src/audio/recorder.py`.
2. Implement: Introduce a circular buffer or similar mechanism to hold the last 11 seconds of audio. Create a separate thread or timer within the recorder that saves a 10-second chunk every 9 seconds, creating the 1-second overlap.
3. Validate: Run the recorder and verify that it generates a sequence of `_chunk_XXXX.wav` files in the session's audio directory. Check the timestamps and file sizes to ensure they are being created correctly. Manually listen to a few consecutive chunks to confirm the overlap.
4. Review Readiness: Ensure the changes are confined to `recorder.py` and that the new chunking logic is clean and efficient.
5. Document: Update `docs/current_state.md` to reflect the new audio chunking mechanism.

Validation Requirements:

Required:
- The recorder generates `.wav` files named with a timestamp and chunk index.
- Each chunk is approximately 10 seconds long.
- Consecutive chunks have a 1-second audio overlap.
- The system remains stable and does not consume excessive memory.

Tests Required:

Out of Scope:

- Deduplicating text from overlapping transcriptions.
- Voice Activity Detection (VAD).
