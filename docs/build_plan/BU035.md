# BU035 — Assistant Session Context Retrieval

Status:
Pending

Goal:
Create a small retrieval layer that gathers session transcripts, summaries, and screenshot metadata for assistant prompts.

Context:
The agent must answer using active or previous session resources. Keep retrieval independent from OpenRouter and UI so it can be validated without agent calls.

Allowed Files:
