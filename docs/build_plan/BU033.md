# BU033 — Filtering Transcriptions

Status:
Pending

Goal:
Add controls to filter the live transcription view to show both, microphone only, or system audio only.

Context:
When both microphone and system audio are being transcribed, the live transcription view can become cluttered. This BU will add filtering options to allow the user to focus on a single audio source.

Allowed Files:
- `src/app/window.py`

Dependencies:
Required:
- BU032

Blocks:
- none

Tasks:
1.  **Modify `src/app/window.py`:**
    - In the `_create_transcription_view` method, add a `QComboBox` or a set of `QRadioButton`s with the options: "All", "You (mic)", and "Them (system)".
    - Connect the `currentIndexChanged` or `toggled` signal of the filter control to a new method, e.g., `_update_transcription_filter`.
    - In the `_update_transcription_filter` method, iterate through the transcription labels in the view and show or hide them based on the selected filter and the source of the transcription (which should be stored as a property of the label).
    - When adding a new transcription in `add_transcription_to_view`, check the current filter and set the visibility of the new label accordingly.

Execution Sequence:
1.  **Understand:** Review how to use filter controls and how to show/hide widgets in PySide6.
2.  **Implement:** Add the filter controls and the filtering logic.
3.  **Validate:** Run the application with live transcription enabled. Record some audio from both sources. Test the filter controls to ensure they are working correctly. Verify that the view updates immediately when the filter is changed.
4.  **Review Readiness:** Ensure the filtering is working as expected and the UI is responsive.
5.  **Document:** Update `docs/current_state.md` and `docs/devlog.md`.
