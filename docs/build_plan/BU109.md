# BU109 — Screenshot Viewer Window

Status:
Completed

Goal:
Replace the two screenshot grid dialogs with a single image-viewer-style window
in the Summary window's navy/cream pixel theme. Also make the assistant's
screenshot citations (BU108) open that viewer on the cited screenshot.

Context:
`_show_screenshots_by_session_id` (`src/app/window.py` ~1329) and
`_show_session_screenshots` (~1964) are ~450-line near-duplicates. Each has a
2-column `QGridLayout` of 300×200 thumbnails, a 100 px plain `QTextEdit` for
context, default-styled `QPushButton`s, and a double-click that opens yet
another dialog (`_show_full_image` / `_toggle_fullscreen`). There is no
prev/next navigation, no zoom inside the viewer, and no in-place description
editing. Context generation is disabled when the session has no summary.
The Summary window (BU100, `_open_summary_window`) set the look to follow:
`QDialog` background `#061946`, `PixelPanel`, `PixelSectionTitle`,
`pixel_mini_button`, `PixelCollapsibleSection`, `PixelButton`, `PixelStatusChip`,
cream `#FFF0BF` / muted `#8EA7D8` text, freely resizable with a size grip, and a
size remembered for the app session.

Target layout:
```
┌ SESSION SCREENSHOTS ──────────────── [-] [fit] [+]    3 / 12 ┐
│ Session name · 14:03:12 (+00:12:31) · #42 · [AI context]      │
│ ┌────────────────────────────────┐ ┌─ DETAILS ──────────────┐ │
│ │                                │ │ ▾ Description   [edit] │ │
│ │  ◀        large image       ▶  │ │ ▾ Preview              │ │
│ │                                │ │ ▾ AI Summary           │ │
│ │                                │ │ ▾ Visible Text         │ │
│ └────────────────────────────────┘ │ ▾ Keywords             │ │
│                                    └────────────────────────┘ │
│ [thumb] [thumb] [THUMB] [thumb] [thumb] ...        (filmstrip) │
│ [Generate context] [Generate missing] [Open folder] [Delete]  [Close] │
└────────────────────────────────────────────────────────────────┘
```

Tasks:
- Create `ScreenshotViewer(QDialog)` in `src/app/screenshot_viewer.py`. It
  takes the DB, `session_id`, `session_name`, an optional
  `focus_screenshot_id`, and callbacks for context generation / deletion.
- Image stage: fit-to-window by default. Zoom via Ctrl+wheel, `+` / `-`,
  and `0` for fit. Drag to pan when zoomed. Prev/next overlay buttons plus
  ←/→, Home/End, and a "3 / 12" counter.
- Header: `PixelSectionTitle("SESSION SCREENSHOTS")`, session name in cream,
  and a meta row with the capture time and offset into the session, a
  `#ID` badge, and a `PixelStatusChip` showing "AI context" or
  "Preview only".
- Details panel on the right (inside a `QSplitter`, collapsible): one
  `PixelCollapsibleSection` each for Description (inline edit + save via
  `update_screenshot_description`, which then calls BU106 `ensure_previews`
  so edits reach retrieval), Preview (BU106 text, muted), AI Summary, Visible
  Text (one item per line) and Keywords. Empty sections show a muted hint
  instead of disappearing.
- Filmstrip: horizontal, scrollable thumbnail strip reusing
  `_load_thumbnail`, with a per-filepath cache and lazy loading of visible
  items. The selected item gets a theme-accent border and each thumbnail has
  a time label. Selection stays in sync with the stage.
- Action bar:
  - "Generate context" (selected) and "Generate missing" (rows without
    `ai_summary`), using the existing `ScreenshotContextThread` /
    `ScreenshotContextBatchThread`.
  - Enabled when the session has a summary OR transcripts; the summary gate
    is removed because the BU106 ±20 s window is enough. The tooltip notes
    that a summary improves quality.
  - Progress shows in the status chip, and the details panel refreshes on
    completion.
  - "Open folder" runs `explorer /select,<file>`.
  - "Delete" keeps the current confirm-and-remove behavior (row, file,
    `description_*.txt`). The viewer stays open and selects the neighbor.
  - "Close".
- Fullscreen toggle (F / F11). Esc leaves fullscreen first, then closes.
- Remember window size and splitter sizes for the app session (same pattern
  as `_summary_window_size`).
- In `window.py`: add `_open_screenshot_viewer(session_id, session_name,
  focus_screenshot_id=None)`, and route `_show_screenshots_by_session_id`,
  `_show_session_screenshots` and `_on_view_screenshots` through it. Delete
  the duplicated dialog code, plus `_show_full_image` / `_toggle_fullscreen`
  / `_edit_screenshot_description` if nothing else calls them.
- Citation chip: when an `AnswerResponse` has `screenshot_refs` (BU108),
  render a small pixel button per ID under the assistant bubble ("View
  screenshot #42"). Clicking it opens the viewer focused on that screenshot
  in the answer's session. A deleted or missing ID shows a status message
  instead of crashing.
- Keep pure helpers Qt-free and testable: index clamp / wrap, zoom-step
  clamp, context-state label, capture-offset formatting.
