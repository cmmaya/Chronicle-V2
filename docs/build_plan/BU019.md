# BU019 — Screenshot Button in UI

Pending

Goal:
Add a button to the UI to trigger the existing screenshot functionality during an active session.

Context:
While the backend functionality for taking screenshots exists, there is no UI control to trigger it. This BU adds a button to make this feature accessible to the user.

Allowed Files:

- `src/screenshots/capture.py`
- `src/app/session_manager.py`
