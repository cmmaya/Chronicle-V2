# BU161 — Any Session Archive Search For Rare Words And Centred Excerpts

Status:
Completed

Goal:
Find a remark said in passing in any session, even when routing (which
reads only summaries) does not pick that session, and keep the matching
sentence inside the excerpt the model sees.

Context:
- Routing sends the model 5 sessions chosen from their profiles; the
  legacy archive-wide search ran only when routing found nothing.
- Excerpts kept the first 500 of a chunk's ~800 characters.

Allowed Files:
- src/assistant/rag_context_builder.py
- src/assistant/service.py
- src/storage/database.py
- tests/test_bu161.py (new), tests/test_bu152.py (test double signature)
- docs/build_plan/BU161.md, docs/build_plan/index.md, docs/current_state.md, docs/devlog.md

Dependencies:
Required:
- BU089, BU152

Blocks:
- none

Tasks:
- Count chunk matches per question term; a term of 3+ letters in at most
  max(5, 0.5% of chunks) is rare.
- Search each rare term alone, rarest first, across all sessions
  (transcripts, summaries, screenshots), up to 4 chunks.
- Merge: lead the chunks of a routed session; other sessions get their own
  sections within 3000 extra characters and join the candidate sessions.
- Cut excerpts around the first matching term, rarest first.

Validation Requirements:
- No rare word: context identical to before.
- Real-database copy: the Toronto question reaches its session.

Tests Required:
- yes: `tests/test_bu161.py`

Out of Scope:
- Using chunk embeddings for paraphrases
- Raising the 5-session routing limit

Definition of Done:
[x] Passing remark found when routing misses its session
[x] No added context without a rare word
[x] Excerpt contains the matched term
[x] Tests pass
