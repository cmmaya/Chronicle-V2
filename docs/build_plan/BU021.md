# BU021 — Add Global Hotkey Library

Status:
Pending

Goal:
Add the `keyboard` library to support global hotkeys and implement a basic listener.

Context:
The existing `QShortcut` implementation only works when the application window is in focus. To support triggering screenshots while the app is minimized, a global hotkey listener is required. This BU adds the necessary library and a placeholder listener.

Allowed Files:
- `requirements.txt`
- `src/app/window.py`

Dependencies:
Required:
- BU019

Blocks:
- BU022

Tasks:
- Add `keyboard` to `requirements.txt`.
- In `MainWindow`, import the `keyboard` library.
- Implement a basic, non-functional listener for `Ctrl+Shift+R` that logs a message to the console.
- Ensure the listener is started in a separate thread to avoid blocking the UI.

Execution Sequence:
1. Understand
2. Implement
3. Validate
4. Review Readiness
5. Document

Validation Requirements:

Required:
- The application must run without errors after adding the new dependency.
- Pressing `Ctrl+Shift+R` (anywhere in the OS) must print a confirmation message to the console.
- The UI must remain responsive while the listener is active.

Tests Required:
- no

Out of Scope:
- Triggering any actual screenshot functionality.
- Removing the old `QShortcut` implementation.

Definition of Done:
