# BU154 — Monochrome Palette

Status:
Completed

Goal:
Map every classic colour to a black / grey / white palette: black
canvas, grey surfaces, light text, no accent except red for live and errors.

Context:
- Cream controls (`#F6E0A6`) carried dark navy text (`#071846`); in the
  corporate theme they become grey `#262626` surfaces, so that text becomes
  light (`#ECECED`).
- No value may also be a key (BU129 rule), so near-duplicate greys
  (`#ECECED`, `#000001`...) stand in where two classic colours share a look.
