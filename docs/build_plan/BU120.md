# BU120 — Dependency Audit And Clean Requirements

Status:
Completed

Goal:
Make `requirements.txt` list exactly what the app imports, so a clean
environment - and later the PyInstaller build - installs everything the app
needs and nothing it does not.

Context:
- Audit of every `import` / `from` in `src/` and `tests/` against
  `requirements.txt` and the installed `.venv312` (BU120 analysis):
  - **Imported but not declared:**
    - `httpx` - `src/assistant/openrouter_client.py:104,176` (sync and async
      chat calls). Only present today because something else pulled it in.
    - `huggingface_hub` - `src/rag/embeddings.py:123`. Arrives transitively
      through `onnx-asr[hub]`, but the app calls it directly, so it must be
      pinned directly.
    - `pytest` - tests only.
  - **Declared but not imported:** `mss` - screenshots use Qt's
    `screen.grabWindow(0)` (`src/screenshots/capture.py:46,89`,
    `src/screenshots/snipping.py:36`).
  - **Dead code pulling dead dependencies:** `src/transcription/whisper.py`
    imports `whisper` and `faster_whisper` and is imported by nothing.
    `src/transcription/processor_parakeet (1).py` is a stray copy.
  - **Leftovers in `.venv312` that nothing uses:** `faster-whisper`,
    `ctranslate2`, `numba`, `llvmlite`, `tiktoken`, `rocm`, `sympy`,
    `networkx`, `Jinja2`, `pillow`, `rich`, `typer`, and others. They come
    from the Whisper era and would bloat a frozen build by hundreds of MB if
    PyInstaller picked them up.
- `docs/setup.md` still says to install Whisper and PyTorch, which is no
  longer true since the Parakeet migration.
- `.venv/` files appear in git history (commit `ee4231e` added
  `.venv/Scripts/*.exe`), so the venv is at least partly tracked.
