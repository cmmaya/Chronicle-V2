# BU042 — Assistant Answer Service

Status:
Pending

Goal:
Coordinate session resolution, context retrieval, OpenRouter answering, and conversation persistence.

Context:
The UI needs one stable service entrypoint so it does not know how retrieval, ambiguity handling, agents, or OpenRouter calls work.

Allowed Files:
- src/assistant/service.py
- docs/current_state.md
- docs/devlog.md

Tasks:
- Create AssistantAnswerService.ask(question, agent_id, explicit_scope, active_session_id=None, selected_session_id=None, conversation_id=None).
- Use AssistantSessionResolver to determine scope.
- If ambiguous, return a structured clarification response with candidate sessions and do not call OpenRouter.
- If needs_clarification, return a concise question asking which session to use.
- For single-session scope, retrieve bounded session context.
- For all-session scope, retrieve bounded cross-session context via tools/search.
- Build OpenRouter messages using selected agent config and retrieved context only.
- Persist user and assistant messages through database conversation methods.
