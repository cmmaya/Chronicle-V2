# BU072 — Add RAG Source Upsert Helpers

Status:
Pending

Goal:
Add database helper methods for inserting or replacing normalized RAG documents and chunks.

Context:
The schema from BU071 needs small write helpers before the index can be rebuilt. Keep this limited to database persistence.

Tasks:
- Add upsert_rag_document(source_type, source_id, session_id, timestamp, title, content_hash, metadata_json) -> int.
- The upsert must use source_type + source_id as the logical identity.
- Add replace_rag_chunks(document_id, chunks) -> None.
- replace_rag_chunks must delete old chunks for the document and insert the provided chunks in one transaction.
- Use JSON strings for metadata_json; do not introduce custom serialization classes.
