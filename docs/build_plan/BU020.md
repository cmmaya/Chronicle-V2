# BU020 — Display Screenshots in UI

Status:
Pending

Goal:
Create a view to display the screenshots taken during a session.

Context:
After taking screenshots, users need a way to view them. This BU implements a gallery or list view to display the screenshots associated with a session.

Allowed Files:
- `ui/main_window.py`
- `db/database_manager.py`

Dependencies:
Required:
- BU019

Blocks:
- None

Tasks:
- Add a UI element (e.g., a button or tab) to open a view of the session's screenshots.
- When this view is opened, fetch the list of screenshots for the selected session from the database.
- Display the screenshots, along with their timestamps, in a scrollable list or grid.

Execution Sequence:
1. Understand
2. Implement
3. Validate
4. Review Readiness
5. Document

Validation Requirements:

Required:
- The UI must provide a way to view all screenshots for a selected session.
- Each screenshot must be displayed with its timestamp.

Tests Required:
- no

Out of Scope:
- Deleting or editing screenshots.
- Full-screen image viewing or zooming.
