Goal:
Implement system audio capture using loopback functionality from the `soundcard` library and integrate it into the chunked recording pipeline.

Context:
This BU adds the second audio source. It adapts the provided proof-of-concept script to fit into the application's architecture, capturing system audio into timestamped chunks just like the microphone audio.

Tasks:
- Add `soundcard` and `soundfile` to `requirements.txt`.
- Create a `SystemAudioRecorder` class that adapts the following methodology to capture loopback audio:

  ```python
  import soundcard as sc
  import soundfile as sf

  # Note: This is a reference. Adapt it to the application's architecture.
  DURATION_SECONDS = 10
  SAMPLE_RATE = 48000

  default_speaker = sc.default_speaker()
  mic = sc.get_microphone(
      id=str(default_speaker.id),
      include_loopback=True
  )

  with mic.recorder(samplerate=SAMPLE_RATE) as recorder:
      data = recorder.record(
          numframes=DURATION_SECONDS * SAMPLE_RATE
      )
  
  # The file writing part should follow the chunking pattern
  # sf.write(OUTPUT_FILE, data, SAMPLE_RATE)
  ```
- Integrate this recorder into the main `audio_capture` module.
- The `SystemAudioRecorder` must use the same chunking mechanism (10-second files + metadata) as the microphone recorder.
- Chunks from the system audio recorder must be saved to the `sessions/<session_id>/audio/system/` directory.
