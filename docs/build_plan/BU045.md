# BU045 — Assistant Clarification Flow UI

Status:
Pending

Goal:
Allow the UI to handle ambiguous session responses by showing candidate sessions for selection.

Context:
When the resolver finds multiple possible sessions, the assistant should ask the user which session they mean instead of answering from the wrong context.

Allowed Files:
- src/app/window.py
- docs/current_state.md
- docs/devlog.md

Tasks:

- Display candidate sessions with name/date in the assistant panel.
- Allow user to choose one candidate and retry the original question with that session as selected scope.
- Clear candidate choices after a successful answer or a new question.
- Keep behavior simple; no modal wizard.
