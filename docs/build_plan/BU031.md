# BU031 — Live Transcription Checkbox

Status:
Pending

Goal:
Add a checkbox to the UI to enable or disable live transcription.

Context:
Live transcription should be an optional feature. This BU will add a checkbox to the UI to allow the user to enable or disable it before starting a session.

Allowed Files:
- `src/app/window.py`
- `src/app/session_manager.py`

Dependencies:
Required:
- BU030

Blocks:
- BU032

Tasks:
1.  **Modify `src/app/window.py`:**
    - In the `MainWindow`'s `_create_central_widget` method, add a `QCheckBox` with the label "Enable live transcription".
    - The checkbox should be placed in the left-side layout, near the "Start Session" button.
2.  **Modify `src/app/session_manager.py`:**
    - In the `start_session` method, add a new parameter, e.g., `enable_live_transcription`.
    - In `MainWindow`, when the "Start Session" button is clicked, get the state of the checkbox and pass it to the `start_session` method.
    - In `SessionManager`, only enable the `live_transcription_callback` if `enable_live_transcription` is `True`.

Execution Sequence:
1.  **Understand:** Review the `MainWindow` and `SessionManager` classes.
2.  **Implement:** Add the checkbox to the UI and modify the `start_session` method.
3.  **Validate:** Run the application. Verify that the checkbox is displayed. Start a session with the checkbox enabled and check the console output for the live transcription logs. Start another session with the checkbox disabled and verify that there are no live transcription logs.
4.  **Review Readiness:** Ensure the checkbox is working correctly and the live transcription is only active when it's enabled.
5.  **Document:** Update `docs/current_state.md` and `docs/devlog.md`.

Validation Requirements:

Required:
- A checkbox for enabling/disabling live transcription must be present in the UI.
- Live transcription must only be active when the checkbox is enabled.
- No new syntax/runtime errors should be introduced.

Tests Required:
- no
