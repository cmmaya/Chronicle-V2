# BU147 — Document Text Extraction (.txt, .md, .pdf, .docx)

Status:
Completed

Goal:
Turn a `.txt`, `.md`, `.pdf` (with a text layer) or `.docx` file into plain
text the assistant can read, with a clear, user-readable refusal for anything
that yields no usable text.

Context:
- Session Documents store text only (BU146). This BU is the one place a file
  becomes that text.
- `src/assistant/reference_doc.py` (BU117) already loads `.txt` correctly:
  size cap, UTF-8 then platform-encoding fallback, NUL-byte binary check,
  line-ending normalisation, `ReferenceDocError` with a status-bar message.
  Reuse it for `.txt` and `.md` instead of writing a second loader.
- No PDF or Word library is installed today (`requirements.txt`,
  `packaging/chronicle.spec`). Two are needed:
  - `pypdf` — pure Python, no native build, enough for text-layer PDFs;
  - `python-docx` — pure Python (needs `lxml`, check whether it is already
    pulled in).
  Both must work in the PyInstaller build (BU126) and the installer (BU127).
- A scanned PDF has no text layer and extracts to (near) nothing. There is no
  OCR (out of scope), so that case must be caught and refused here rather than
  stored as an empty document that silently answers nothing.
- Extraction can take a few seconds on a long PDF; callers will run it on a
  background job (BU148), so this module stays Qt-free and synchronous.

Tasks:
- `requirements.txt`: add `pypdf` and `python-docx`, pinned like the rest.
  `chronicle.spec`: add whatever hidden imports / data the build needs, and
  confirm with a build that both import inside the frozen app.
- Config (`SESSION_DOCUMENTS`): `min_text_chars` (e.g. 40) — below this
  after extraction the document is refused; `max_text_chars` (e.g. 400000) —
  extracted text over this is refused rather than truncated silently.
- `src/assistant/session_documents.py`, Qt-free and network-free:
  - `DocumentError(Exception)` — message fit to show the user.
  - `ExtractedDocument` dataclass: `name`, `file_type`, `file_bytes`, `text`,
    `char_count`.
  - `extract_document(path) -> ExtractedDocument`:
    - checks: exists, not a folder, extension in
      `SESSION_DOCUMENTS["allowed_extensions"]`, size within `max_file_bytes`;
    - `.txt` / `.md`: via `reference_doc.load_reference_text` (with the
      session-documents size cap); `ReferenceDocError` becomes `DocumentError`;
    - `.pdf`: `pypdf`, page by page, pages joined with a blank line; an
      encrypted PDF that cannot be opened with an empty password is refused
      ("This PDF is password-protected");
    - `.docx`: `python-docx`, paragraphs in order plus table cell text row by
      row; headers/footers ignored;
    - normalise whitespace (collapse runs of blank lines, strip trailing
      spaces) so paragraph splitting in BU149 works the same for every type;
    - fewer than `min_text_chars` → `DocumentError("No readable text found in
      <name> — scanned PDFs are not supported")` (wording adjusted per type);
    - more than `max_text_chars` → refused with the size in the message;
    - any library exception → `DocumentError("Could not read <name>: ...")`;
      never a partial result.
  - `is_allowed_document(path) -> bool` for drag-enter checks.
