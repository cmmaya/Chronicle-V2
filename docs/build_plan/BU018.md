# BU018 — Display Summary in UI

Status:
Pending

Goal:
Allow the user to click on a summarized session and view the generated summary.

Context:
Once a session is summarized, the user needs a way to see the output. This BU implements the UI to display the summary text.

Allowed Files:
- `src/app/window.py`
- `src/storage/database.py`

Dependencies:
Required:
- BU017

Tasks:

- When a session is selected, fetch the summary from the database using `db/database_manager.py`.
- Display the summary text in a new window, a dialog box, or a dedicated area in the main window.
