# BU032 — Live Transcription Display

Status:
Pending

Goal:
Implement the "chat-like" window to display the live transcriptions.

Context:
This BU will create the UI component to display the live transcriptions in real-time. It will be a scrollable area that shows the transcriptions as they are generated, distinguishing between the microphone and system audio.

Allowed Files:
- `src/app/window.py`

Dependencies:
Required:
- BU029
- BU031

Blocks:
- BU033

Tasks:
1.  **Modify `src/app/window.py`:**
    - In the `MainWindow`, create a new method, e.g., `_create_transcription_view`, that creates a `QScrollArea` and a `QVBoxLayout` to hold the transcription labels.
    - In the `_create_central_widget` method, call `_create_transcription_view` and add the resulting widget to the right-side layout.
    - Create a new method, e.g., `add_transcription_to_view`, that takes the transcription text and source (`mic` or `system`). This method will create a new `QLabel` for the transcription, style it based on the source (e.g., different colors or alignment), and add it to the transcription view.
    - In the `SessionManager`'s `handle_live_transcription` method, call the `add_transcription_to_view` method using the `live_transcription_ui_callback`.

Execution Sequence:
1.  **Understand:** Review how to create custom widgets and layouts in PySide6.
2.  **Implement:** Create the transcription view and the method to add new transcriptions to it.
3.  **Validate:** Run the application with live transcription enabled. Speak into the microphone and play some system audio. Verify that the transcriptions are displayed in the new view in real-time, with a clear distinction between the two sources.
4.  **Review Readiness:** Ensure the transcription view is updating correctly and the UI remains responsive.
5.  **Document:** Update `docs/current_state.md` and `docs/devlog.md`.

Validation Requirements:

Required:
- Live transcriptions must be displayed in the UI in real-time.
- Transcriptions from the microphone and system audio must be visually distinct.
- The transcription view must be scrollable.
- No new syntax/runtime errors should be introduced.

Tests Required:
- no

Out of Scope:
- Filtering the transcriptions.
