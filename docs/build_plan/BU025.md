# BU025 — Integrate WebRTC VAD

Status:
Pending

Goal:
Integrate WebRTC Voice Activity Detection (VAD) to filter out silent audio chunks before they are processed by the transcription model.

Context:
The system currently transcribes all audio chunks, including those that contain only silence. This is inefficient and can lead to model "hallucinations" where the model imagines words in the noise. By using VAD, we can discard silent chunks, saving processing time and improving transcription accuracy.

Allowed Files:
- `src/audio/recorder.py`

Dependencies:
Required:
- BU023

Blocks:
- none

Tasks:
- Add a VAD library (e.g., `webrtcvad-wheels`) to the project's dependencies.
- In `AudioRecorder`, after an audio chunk is created but before it is saved, process it with the VAD.
- The VAD should determine if the chunk contains a sufficient amount of speech.
- If the chunk is mostly silent, it should be discarded instead of being written to a file.
- The threshold for what constitutes "sufficient speech" should be configurable.

Execution Sequence:
1. Understand: Research and choose a suitable Python VAD library. Review the chunking mechanism in `AudioRecorder` from BU023.
2. Implement:
    - Add the chosen VAD library to the project.
    - In the `AudioRecorder`'s chunking loop, create an in-memory audio chunk.
    - Pass the chunk to the VAD function.
    - If the VAD returns `False` (no speech), discard the chunk and continue.
    - If the VAD returns `True` (speech detected), proceed with saving the chunk to a `.wav` file as before.
3. Validate: Run the recorder in a quiet environment and confirm that few or no chunk files are generated. Then, speak and confirm that chunk files are generated as expected.
4. Review Readiness: Ensure the VAD integration is efficient and does not introduce significant latency.
5. Document: Update `docs/current_state.md` to mention the new VAD pre-filtering step.
