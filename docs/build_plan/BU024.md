# BU024 — Add Transcription Deduplication and Context

Status:
Pending

Goal:
Update the transcription process to handle overlapping audio chunks by deduplicating repeated text and maintaining conversational context.

Context:
BU023 introduced overlapping audio chunks, which will cause the transcription model to process the same audio twice, leading to repeated phrases in the output. This BU implements a deduplication strategy to create a clean, final transcript. It also introduces context from previous transcriptions to improve the accuracy of the next one.

Allowed Files:
- `src/transcription/processor.py`
- `src/transcription/parakeet.py`

Dependencies:
Required:
- BU023

Blocks:
- none

Tasks:
- In `TranscriptionProcessor`, implement a text-based deduplication algorithm. This could involve comparing the end of the last transcript with the beginning of the new one.
- Maintain a rolling window of the most recent transcriptions to serve as context.
- Modify the call to the transcription model in `parakeet.py` and `processor.py` to pass this context as an `initial_prompt`.
- Limit the size of the context window to avoid performance degradation.

Execution Sequence:
1. Understand: Review `TranscriptionProcessor` and how it currently handles audio files.
2. Implement:
    - Add logic to `_transcribe_and_store` to manage a context string.
    - After a new transcription is received, compare it with the previous one to find and remove the overlapping text.
    - Append the cleaned text to the context.
    - Pass the context string to `self.parakeet.transcribe`.
    - Update `parakeet.py` to accept and use the `initial_prompt`.
3. Validate: Process a series of overlapping chunks. Verify that the final stored transcript in the database does not contain duplicated phrases from the overlaps. Check that the `initial_prompt` is being passed to the model.
4. Review Readiness: Ensure the deduplication logic is robust and the context management is efficient.
5. Document: Update `docs/current_state.md` with details on the new transcription processing logic.
