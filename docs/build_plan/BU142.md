# BU142 — Chronological, Timestamped Session Evidence

Status:
Completed

Goal:
The Specific Session prompt shows transcript excerpts in time order with HH:MM:SS, uncut, and tells the model when the transcript is still growing.

Context:
- `_question_evidence_prompt` printed `[session name] (source): text[:300]` in BM25 order: no timestamps (the system prompt asks to cite them), a second cut after the retriever's, and no way to answer "at the end of the class".
- A live or just-stopped session has no summary and a transcript that ends early; the model read that as "never said".
