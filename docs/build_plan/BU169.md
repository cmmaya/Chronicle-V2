# BU169 — Speakers In Assistant Context

Status:
Completed

Goal:
Questions about a diarized session can be answered by speaker ("what did
the professor ask?" -> the answer can point to Speaker 2's turns).

Context:
- The context builders label transcript lines by source (microphone /
  system).
- BU164 already serves the diarized rows; this BU makes the speaker labels
  show up in the evidence and in the index.

Tasks:

- Indexed chunk text includes the speaker labels, so searching for
  "Speaker 2" finds that speaker's turns.
- For a diarized session, the prompt notes that speakers are numbered
  automatically and the split may be imperfect.
